PROJECT OVERVIEW
This project explores factors affecting student academic performance using data analysis techniques.
TOOLS USED
1.Python
2.Pandas
3.NumPy
4.Matplotlib
KEY ANALYSIS PERFORMED
1.Data Cleaning & Inspection
2.Exploratory Data Analysis (EDA)
3.GPA Distribution Analysis
4.Impact of Tutoring & Parental Support
5.Correlation Analysis
6.Simple Linear Regression
KEY FINDINGS
1.Absences show strong negative relationship with GPA
2.Parental Support has stronger influence than Tutoring
3.Study Time shows weak linear relationship with GPA
DATASET
Student performance dataset from Kaggle.
