PROJECT OVERVIEW
This project analyzes student academic performance using data analytics techniques to identify the key factors influencing GPA. The objective is to extract meaningful insights from educational data and understand how behavioral and environmental variables impact student outcomes.
TOOLS USED
1.Python
2.Pandas
3.NumPy
4.Matplotlib
5.Jupyter Notebook
KEY ANALYSIS PERFORMED
1.Data Cleaning & Inspection
2.Exploratory Data Analysis (EDA)
3.GPA Distribution Analysis
4.Impact Analysis (Tutoring & Parental Support)
5.Correlation Analysis
6.Simple Linear Regression
KEY FINDINGS
1.Absences exhibit a strong negative relationship with GPA
2.Parental Support demonstrates a greater influence on GPA compared to Tutoring
3.Study Time shows a weak linear relationship with GPA
4.Regression modeling indicates limited predictive power for certain variables
DATASET
Student Performance Dataset sourced from Kaggle.
LEARNING OUTCOMES
Through this project, the following skills were developed:
1.Data preprocessing & inspection
2.Statistical analysis & interpretation
3.Data visualization
4.Identifying patterns & relationships
5.Basic predictive modeling
