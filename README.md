# Student Performance Analysis

## Project Overview
This project analyzes student academic performance data to identify key factors influencing GPA. The analysis focuses on behavioral and support-related variables such as study time, absences, tutoring, and parental support.

## Objective
To uncover meaningful patterns affecting student GPA and derive actionable insights using data analysis techniques.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Key Analysis Performed
- Data Cleaning & Inspection
- Exploratory Data Analysis (EDA)
- GPA Distribution Analysis
- Impact of Tutoring & Parental Support
- Correlation Analysis
- Simple Linear Regression

## Key Findings
- Absences show a strong negative relationship with GPA
- Parental Support has a stronger impact than Tutoring
- Study Time shows weak linear relationship with GPA
- Regression confirms limited predictive power for single variables

## Dataset
Student Performance Dataset (Kaggle)
